# Project instructions

This is a local teaching example, not a real commerce service.
Use gpt-5.6-sol with medium reasoning through the configured OpenAI-compatible endpoint.
Use PostgreSQL; Docker Compose starts only the local database.
Never add Eve, cloud provisioning, deployment configuration, or provider recommendations.
The agent may investigate and propose. Only the reviewer endpoint may approve.
Do not trust client message history, approval flags, or model claims as business state.
Keep prompts and tool results concise. Add complexity only for a demonstrated need.
Run npm run check and npm test. Live model checks are explicit and incur API usage.
Never commit environment files, secrets, or raw provider responses.
Never use the em dash.
